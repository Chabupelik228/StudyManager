# 📚 StudyManager — Умная платформа управления учебным процессом

**StudyManager** — это клиент-серверная платформа, разработанная для комплексного управления учебной группой. Она автоматизирует отслеживание посещаемости, расписание занятий, дежурства, а также обеспечивает прозрачную коммуникацию за счёт моста между Telegram и ВКонтакте.

Ключевая особенность проекта — использование гибридной архитектуры, объединяющей современное веб-приложение (Vue 3) с Telegram/VK ботами и реактивным бэкендом (FastAPI + WebSockets) для мгновенной синхронизации данных.

---

## 🎯 1. Архитектура и концепция

Проект решает задачи цифровизации рутинных учебных процессов старосты и преподавателей, объединяя различные каналы связи в единую экосистему:

1. **Единое окно управления:** Веб-интерфейс предоставляет удобную панель для контроля расписания, отметки отсутствующих и распределения дежурных (доска/мел).
2. **Омниканальная коммуникация (Message Bridge):** Встроенный бот автоматически ретранслирует и синхронизирует сообщения между рабочими чатами в Telegram и ВКонтакте, объединяя потоки информации.
3. **Реал-тайм обновления:** Любые изменения, вносимые старостой в веб-интерфейсе (отметка посещаемости или смена расписания), мгновенно рассылаются всем подключенным клиентам по WebSocket.

---

## 🏗 2. Архитектура и сетевой стек

Архитектура проекта разделена на три независимых контура: **Frontend (Vue 3 SPA)**, **Backend (FastAPI/Python)** и **Bot Worker (Aiogram)**.

### Схема прохождения данных
`Web Client (Vue 3)` / `Telegram Mini App` ➔ `FastAPI REST / WebSocket` ➔ `PostgreSQL (SQLAlchemy)`
`VK Chat` ➔ `Aiogram Bot / Message Bridge` ➔ `Telegram Chat`

1. **Web & API Backend:** Асинхронный сервер на FastAPI обрабатывает HTTP-запросы от Vue-фронтенда. Тяжёлые задачи, такие как парсинг и синхронизация, выносятся в BackgroundTasks.
2. **Message Bridge (VK ↔ Telegram):** Выделенный модуль прослушивает события из ВКонтакте и Telegram, связывая их через таблицу `message_bridge` (сопоставление `tg_msg_id` и `vk_msg_id`).
3. **Реактивное состояние (WebSockets):** Сервер управляет пулом активных WS-соединений (`app.websocket.manager`), оповещая фронтенд о любых изменениях в расписании или посещаемости для немедленной перерисовки UI.

## 🕵️‍♂️ 3. Интеграции и управление состоянием

### Авторизация через Telegram (Mini App)
- **Бесшовная аутентификация:** Веб-приложение интегрировано в Telegram. Бэкенд валидирует `initData`, подписанные секретным ключом бота (`validate_tg_init_data`), гарантируя подлинность пользователя без необходимости ручного входа по паролю.
- **Маппинг студентов:** Контекст пользователя (`UserContext`) динамически связывает Telegram ID со списком студентов в базе данных.

### Синхронизация расписания и дежурств
- **Замены и отмены:** Система поддерживает механизм оверрайдов (замен) для расписания. Все изменения накладываются поверх базового расписания "на лету" без деструктивных изменений основы.
- **Умные дежурства:** Сервис дежурств автоматически исключает студентов из чёрного списка (`EXCLUDED_DUTY_STUDENT_IDS`) и распределяет обязанности, сохраняя историю.

## 🛡 4. Безопасность и анти-абуз

Система спроектирована с учетом разграничения прав и защиты от несанкционированного изменения данных.

### Ролевая модель и аудит
- **Role-Based Access Control (RBAC):** Эндпоинты защищены декораторами зависимостей (`require_admin`), пуская только авторизованных пользователей с админскими правами к мутирующим операциям.
- **Журнал действий (Audit Log):** Любое изменение в системе (отметка отсутствующего, назначение дежурного, смена расписания) строго фиксируется в таблице `action_logs` с привязкой к имени администратора, типу действия и точному времени.
- **Мониторинг онлайна:** Таблица `admins_online` позволяет отслеживать активность администраторов в реальном времени.

## 💻 5. Стек технологий

- **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0, Asyncpg, Pydantic.
- **Web Frontend:** Vue 3, Vite, Pinia (State Management), Tailwind CSS.
- **Database:** PostgreSQL (основное хранилище), Alembic (миграции).
- **Bots & Integrations:** Aiogram (Telegram bot), VK API (Интеграция), Google GenAI.
- **Infrastructure:** Docker, Docker Compose, Nginx.

## ⚙️ 6. Запуск и сборка

### Требования
- **Для запуска:** Linux VPS, Docker & Docker Compose, Node.js 18+.

### Запуск в режиме разработки (Dev)
```bash
# Бэкенд и База Данных (в Docker)
docker-compose up -d db
alembic upgrade head
# Запуск FastAPI
uvicorn app.main:create_app --reload --port 8000

# Фронтенд
cd frontend
npm install
npm run dev
```

### Production-деплой
Все компоненты легко поднимаются через оркестратор Docker Compose:
```bash
docker-compose up -d --build
```
Готовый статический бандл фронтенда можно собрать командой `npm run build` в папке `frontend` и раздавать через Nginx.
